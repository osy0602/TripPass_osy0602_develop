# ✈️ TRIPPASS
![image](https://github.com/osy0602/TripPass_osy0602_develop/blob/main/trippassreadme/banner.jpg)
### 1. 🤖 AI Chatbot Itinerary Generation
- **Personalized Recommendations:** Users input their travel destination and duration to receive a unique travel itinerary generated by an AI chatbot.
- **Advanced AI Integration:** Developed using the **OpenAI API** with sophisticated **Prompt Engineering** to recommend destinations that align with the user's preferences.
- **Hallucination-Free Responses:** Implemented **Function Calling** to ensure the chatbot provides accurate and reliable information by calling predefined functions, effectively mitigating AI hallucination issues.

### 2. 🤝 Travel Crew Matching
- **Connect with Other Travelers:** Recommends other travelers or 'crews' who are in the same location during the same time period.
- **Enhancing Solo Travel:** Offers a unique opportunity for solo travelers to connect, share experiences, and create new memories.

### 3. 🖥️ Main Travel Dashboard (Frontend)
- **User-Centric Interface:** Built with **React** and **Redux** for efficient state management and a seamless user experience.
- **Dynamic Itinerary Display:** After verifying user information, the main travel page fetches itinerary data from our database via a custom API and renders it in an intuitive UI.

### 4. ⚙️ Backend & Database
- **API:** Developed a efficient API to handle all database interactions, including user data, itineraries, and crew matching logic.
- **Structured Database Design:** Designed a scalable database schema to store and manage all application data effectively.

### 5. ☁️ Infrastructure & Deployment
- **Cloud-Based Environment:** The entire application is developed and operates on an **AWS EC2** instance.
- **Containerization:** Utilizes **Docker** to containerize the application, ensuring consistency across development, testing, and production environments.
